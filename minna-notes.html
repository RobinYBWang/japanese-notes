📖 文法總表：N5（《大家的日本語》初級I）基礎文法整理（唯讀參考）。點 🔊 可聽例句發音。

1. 基礎句型與判斷

這是日文最基礎的骨架，用來定義或否定事物。

A は B です（A 是 B）
私はエンジニアです。（我是工程師。）
これは私の新しいモニターです。（這是我的新螢幕。）
A は B では ありません（A 不是 B）
私は学生ではありません。（我不是學生。）
今日は日曜日ではありません。（今天不是星期日。）
A は B ですか（A 是 B 嗎？）
あなたは台湾人ですか。（你是台灣人嗎？）
それは新しいカメラですか。（那是新的相機嗎？）
A も B です（A 也是 B）
私もエンジニアです。（我也是工程師。）
妹も台北に住んでいます。（我妹妹也住在台北。）
A の B（A 的 B）
会社のパソコン（公司的電腦）
私のバイク（我的機車）

2. 指示詞與存在

用來指出事物的相對位置，以及描述人或物品的存在狀態。

これ / それ / あれ / どれ（這 / 那 / 那個 / 哪一個）
これは美味しいコーヒーです。（這是好喝的咖啡。）
あなたのバイクはどれですか。（你的機車是哪一輛？）
ここ / そこ / あそこ / どこ（這裡 / 那裡 / 那裡 / 哪裡）
ここは台北です。（這裡是台北。）
会議室はどこですか。（會議室在哪裡？）
あります / います（有 / 存在）
あります 用於無生命，います 用於有生命。
机の上にパソコンがあります。（桌子上有電腦。）
オフィスに部長がいます。（辦公室裡有經理。）

3. 動詞基礎（ます形系列）

日文動詞的「禮貌型態」，用於日常陳述與時態變化。

〜ます（肯定・現在／未來）
毎日プログラムを書きます。（我每天寫程式。）
週末は海へ行きます。（週末我要去海邊。）
〜ません（否定・現在／未來）
今日は残業しません。（我今天不加班。）
朝ごはんは食べません。（我不吃早餐。）
〜ました（肯定・過去）
昨日、新しいモニターを買いました。（我昨天買了新螢幕。）
先月、日本へ行きました。（我上個月去了日本。）
〜ませんでした（否定・過去）
昨日は忙しかったですから、寝ませんでした。（因為昨天很忙，所以沒有睡覺。）
週末はどこへも行きませんでした。（週末哪裡都沒去。）

4. 助詞用法（句子的結構膠水）

助詞決定了名詞在句子中的功能（如同程式裡的指標）。

は（wa）：提示句子的主題
私は台北に住んでいます。（我住在台北。）
このカメラは高いです。（這台相機很貴。）
が（ga）：提示主語（能力、喜好或客觀存在）
私はダイビングが好きです。（我喜歡潛水。）
机の上に本があります。（桌子上有書。）
を（o）：提示動作的受詞
毎日、コーヒーを飲みます。（我每天喝咖啡。）
今、コードを書いています。（我現在正在寫程式碼。）
に（ni）：具體時間、目的地或存在位置
9時に会社へ行きます。（9點去公司。）
台北に住んでいます。（住在台北。）
で（de）：動作發生的場所、手段或工具
バイクで会社へ行きます。（騎機車去公司。）
レストランでご飯を食べます。（在餐廳吃飯。）
と（to）：表示「和（某人）」或並列
友達と海へ行きます。（和朋友去海邊。）
机の上にペンとノートがあります。（桌子上有筆和筆記本。）

5. 形容詞與副詞

用來修飾名詞或描述狀態。

い形容詞（字尾是「い」）
台湾の夏は暑いです。（台灣的夏天很熱。）
新しいモニターは大きいです。（新螢幕很大。）
な形容詞（修飾名詞時加「な」）
台北はとてもにぎやかな町です。（台北是非常熱鬧的城市。）
私の部屋は静かです。（我的房間很安靜。）

6. 基本接續與助動詞

讓句子產生更多互動與時間邏輯。

〜から / 〜まで（從〜 / 到〜）
9時から6時まで働きます。（我從9點工作到6點。）
家から会社までバイクで30分です。（從家裡到公司騎機車要30分鐘。）
〜てください（請做某動作，搭配て形）
ここに名前を書いてください。（請在這裡寫下名字。）
ちょっと待ってください。（請稍等一下。）
〜ましょう / 〜ませんか（一起做…吧 / 要不要一起…？）
一緒に昼ごはんを食べましょう。（我們一起吃午餐吧。）
明日、一緒に海へ行きませんか。（明天要不要一起去海邊？）

7. 形容詞的變化與比較

形容詞會隨時態改變，也用來做比較（第12課）。

い形：過去〈〜かったです〉／否定〈〜くないです〉／過去否定〈〜くなかったです〉
昨日は暑かったです。（昨天很熱。）
この本は高くないです。（這本書不貴。）
先週は忙しくなかったです。（上週不忙。）
な形：過去〈〜でした〉／否定〈〜じゃありません〉／過去否定〈〜じゃありませんでした〉
町はにぎやかでした。（那城鎮以前很熱鬧。）
部屋はきれいじゃありません。（房間不乾淨。）
テストは簡単じゃありませんでした。（考試不簡單。）
形容詞連接：い形〜くて／な形〜で
このカメラは安くて、いいです。（這台相機又便宜又好。）
彼女はきれいで、親切です。（她又漂亮又親切。）
比較：AはBより〜／Aのほうが〜／〜（の中）でいちばん〜
台北は東京より暑いです。（台北比東京熱。）
バイクより車のほうが速いです。（比起機車車子更快。）
果物の中でりんごがいちばん好きです。（水果之中我最喜歡蘋果。）

8. 動詞て形（用途廣）

動詞的「て形」是許多 N5 句型的基礎（第14–16課）。

〜ています（正在／狀態、居住、職業）
今、ご飯を食べています。（現在正在吃飯。）
台北に住んでいます。（我住在台北。）
銀行で働いています。（我在銀行工作。）
〜てもいいです（可以…／許可）
ここに座ってもいいですか。（可以坐這裡嗎？）
写真を撮ってもいいです。（可以拍照。）
〜てはいけません（不可以…／禁止）
ここでたばこを吸ってはいけません。（這裡不可以抽菸。）
授業中に寝てはいけません。（上課中不可以睡覺。）
〜てから／〜て、〜（動作先後順序）
ご飯を食べてから、勉強します。（吃完飯後讀書。）
朝起きて、顔を洗って、会社へ行きます。（早上起床、洗臉，然後去公司。）

9. 動詞ない形

表示「不做／必須做」的句型（第17課）。

〜ないでください（請不要…）
ここに車を止めないでください。（請不要在這裡停車。）
心配しないでください。（請不要擔心。）
〜なければなりません（必須…）
明日までにレポートを出さなければなりません。（明天前必須交報告。）
薬を飲まなければなりません。（必須吃藥。）
〜なくてもいいです（不…也可以）
明日は来なくてもいいです。（明天不來也可以。）
急がなくてもいいです。（不用急。）

10. 動詞辭書形・た形

辭書形與た形延伸出的常用句型（第18–19課）。

辭書形＋ことができます（會／能夠）
私は日本語を話すことができます。（我會說日語。）
ここで泳ぐことができますか。（這裡可以游泳嗎？）
辭書形＋まえに（在…之前）
寝るまえに、歯を磨きます。（睡覺前刷牙。）
食事のまえに、手を洗います。（吃飯前洗手。）
〜たことがあります（曾經…過）
日本へ行ったことがあります。（我去過日本。）
寿司を食べたことがありますか。（你吃過壽司嗎？）
〜たり〜たりします（又…又…、列舉動作）
週末は本を読んだり、映画を見たりします。（週末看看書、看看電影。）
〜くなります／〜になります（變得…）
寒くなりました。（變冷了。）
彼は先生になりました。（他當上老師了。）

11. 願望與授受

表達想要，以及給予、得到（第7、13課）。

〜たいです（想做…）
日本へ行きたいです。（我想去日本。）
水が飲みたいです。（我想喝水。）
Nが ほしいです（想要…〈東西〉）
新しいパソコンがほしいです。（我想要新電腦。）
時間がほしいです。（我想要有時間。）
〜をあげます／もらいます（給／得到）
私は友達にプレゼントをあげました。（我送了朋友禮物。）
友達に本をもらいました。（我從朋友那得到一本書。）

12. 更多助詞與小詞

N5 常用但容易漏掉的助詞與句尾詞。

へ（方向：去／來／回）
会社へ行きます。（去公司。）
国へ帰ります。（回國。）
から（原因：因為…）
時間がありませんから、急ぎます。（因為沒時間，所以趕快。）
寒いから、窓を閉めます。（因為冷，把窗戶關上。）
や（列舉：…和…等）
机の上に本やペンがあります。（桌上有書和筆等。）
位置詞＋に あります／います（うえ・した・なか・まえ・うしろ・となり）
机の上に猫がいます。（桌上有貓。）
銀行はコンビニのとなりにあります。（銀行在便利商店隔壁。）
句尾 ね／よ（ね＝確認・同感；よ＝提醒對方）
いい天気ですね。（天氣真好呢。）
この店は安いですよ。（這家店很便宜喔。）
もう〜ました／まだ〜ていません（已經／還沒）
もう昼ごはんを食べました。（已經吃過午餐了。）
まだ宿題をしていません。（還沒寫作業。）

13. 疑問詞總覽

把常用疑問詞一次記起來。

常用疑問詞一覽
何〈なに／なん〉＝什麼｜誰〈だれ〉／どなた＝誰｜いつ＝何時｜どこ＝哪裡｜どれ／どの＝哪個｜いくら＝多少錢｜いくつ＝幾個／幾歲｜どうして／なぜ＝為什麼｜どんな＝什麼樣的｜どうやって＝怎麼做
これはいくらですか。（這個多少錢？）
誕生日はいつですか。（生日是什麼時候？）
どうして遅れましたか。（為什麼遲到？）
どんな音楽が好きですか。（你喜歡什麼樣的音樂？）

14. 數量詞・量詞

數東西時要配合正確的量詞（第11課）。

常見量詞
〜つ(一般物)｜〜個〈こ〉｜〜枚〈まい〉(薄的)｜〜本〈ほん〉(細長)｜〜杯〈はい〉(杯裝)｜〜匹〈ひき〉(動物)｜〜人〈にん〉(人)｜〜回〈かい〉(次數)｜〜歳〈さい〉(年齡)
りんごを三つ買いました。（買了三個蘋果。）
切手を五枚ください。（請給我五張郵票。）
ビールを二本飲みました。（喝了兩瓶啤酒。）
一週間に三回、日本語を勉強します。（一週學三次日語。）
